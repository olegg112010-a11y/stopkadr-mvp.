# Бесплатный MVP — каталог авторских фотографий

Это стартовый фронтенд-прототип без платежей.

## Что уже работает
- Адаптивная главная страница в персиково-розовой палитре.
- Каталог и фильтры.
- Демо-профиль автора.
- Отправка фотографии на локальную модерацию.
- Список отправленных работ в кабинете.
- Ограничение формата и размера файла на стороне браузера.

## Важно: ограничения прототипа
Это только демонстрация в браузере, не готовый публичный сервис:
- Регистрация хранится в `localStorage` и не защищена.
- Загруженные файлы остаются в текущем браузере; на сервер не отправляются.
- Модерация не имеет административной панели и пока не может одобрять публикации.
- Данные можно потерять при очистке данных браузера.
- Не добавляйте реальные личные данные.
- Перед публичным запуском нужны серверная авторизация, база данных, защищённое хранилище, административная модерация, правила площадки, политика обработки персональных данных, механизм удаления контента и подтверждение прав авторов.
- Не подключайте платежи, пока не согласованы провайдер, юридическая схема и налоги.

## Как открыть
Самый простой способ — открыть `index.html` в современном браузере. Для дальнейшей разработки проект можно перенести в Next.js или другой стек с серверной частью.

## Следующий шаг
1. Утвердить название и домен.
2. Перенести интерфейс в репозиторий.
3. Добавить серверную авторизацию и базу данных.
4. Реализовать административную очередь модерации.
5. Проверить юридические документы и хостинг для данных пользователей.
